# ApplePickerPrototype

This project is an **Apple Picker** game prototype developed with Unity.

## Project Information
* **Unity Version:** 6000.0.6f1 (Unity 6)
* **Target Platform:** Windows (Standalone)

---

## How to Run the Project

1. **Add the Project to Unity Hub:**
   * Open the Unity Hub application.
   * In the **Projects** tab, click the **Add** (Add project from disk) button.
   * Select the project's root directory to add it.

2. **Open the Main Scene:**
   * If the main scene does not load automatically when the project opens, follow this path in the **Project** panel at the bottom:
     `Assets` > `Scenes` > **`SampleScene.unity`**
   * Double-click the `SampleScene` scene to open it.

3. **Start the Game:**
   * Click the **Play (▶)** button at the top of the editor to run the game.

---

## Controls
* **Basket Movement:** Control the basket by moving the mouse left or right along the horizontal axis.
